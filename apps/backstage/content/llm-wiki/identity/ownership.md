# Ownership

Who owns this repository, from version-control evidence.

- **Organization**: The Digital Group (TDG). Remote is Azure DevOps:
  `https://tdgteams-tdgproject.visualstudio.com/TDG%20HRMS/_git/TDG%20HRMS%20DB`.
- **SCM**: Git on Azure DevOps Repos. Default branch `master`.
- **Issue tracker**: Azure DevOps Boards. Work items are referenced as `PBI#<n>`
  throughout SP change-log comment blocks and as branch names (`#111201`,
  `#112611`, ...).
- **Change process**: Pull-request based. Commit subjects are
  `Merged PR <n>: <Feat|Fix|...>: <description>` (e.g. "Merged PR 21787: Feat:
  New module added for Mobile Management").
